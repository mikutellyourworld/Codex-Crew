# Changelog

## 0.7.0

- Renamed and rebranded the public distribution as Codex Crew.
- Made Codex the default and limited public backend selection to Codex and
  authenticated OpenAI-compatible or FreeChain profiles.
- Added multiple OpenAI-compatible profiles with truthful connection status.
- Added Codex account switching, native tool governance, and persisted usage and
  context counters.
- Bundled the pinned Codex ACP adapter in desktop packages.
- Added Drive Sentinel as an enabled-by-default built-in app with distinct
  terminal-style branding and conservative cleanup boundaries.
- Moved the default data home and gateway port to the Codex Crew identity.
- Replaced product, tray, loading, installer, and web artwork with the Codex Crew
  terminal mark.
- Removed private review automation, inherited release endpoints, and archived
  internal planning material from the public distribution.
