# Codex Crew documentation

Codex Crew is a local-first agent gateway with a web dashboard, desktop shell,
schedules, apps, memory, and governed tool execution.

- [Getting started](getting-started.md)
- [Configuration](configuration.md)
- [Security](security.md)

The public 0.7 runtime supports Codex and authenticated OpenAI-compatible or
FreeChain profiles. Drive Sentinel is installed and enabled by default.
